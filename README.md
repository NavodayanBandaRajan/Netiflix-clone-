# Netiflix-clone-
Project 8

🎬 Netflix Clone Website

📖 Overview

This project is a responsive Netflix Clone landing page built using HTML and CSS with AOS (Animate On Scroll) animations. The website is inspired by the official Netflix homepage and recreates its modern dark-themed design, attractive hero section, feature cards, FAQ section, and footer layout.

The purpose of this project is to practice front-end web development concepts such as responsive design, Flexbox, CSS Grid, animations, hover effects, forms, and layout structuring.

---

✨ Features

🎥 Hero Section

- Netflix-style background image
- Dark gradient overlay
- Attractive heading and subtitle
- Email input field with "Get Started" button
- Responsive design for different screen sizes

🔥 Navigation Area

- Netflix logo
- Sign Up button
- Smooth AOS entrance animations

📺 Feature Cards

The website contains multiple feature cards showcasing:

- Watch on TV
- Download Shows
- Watch Anywhere
- Create Kids Profiles

Each card includes:

- Relevant image
- Feature title
- Description
- Hover animation effects

🎨 Animations

This project uses the AOS (Animate On Scroll) library for modern scroll-based animations such as:

- Fade Right
- Fade Left
- Fade Up
- Zoom In
- Zoom In Up

❓ FAQ Section

A Netflix-style Frequently Asked Questions section displaying common user queries such as:

- What is Netflix?
- How much does Netflix cost?
- Where can I watch?
- How do I cancel?

🌐 Language Selector

A language selection box is included in the footer with support for:

- English
- Hindi

📱 Fully Responsive Design

The website is optimized for:

- Mobile devices
- Tablets
- Desktop screens

Responsive techniques used:

- Flexbox
- CSS Grid
- Media Queries
